# Turtle Tower Defense

Keep the trash out of the lake! Place turtles along the campus walkways to break litter apart before it reaches the water.

**Play:** open `index.html` in a browser, or visit the GitHub Pages link for this repository.

- 9 turtles, each with 3 upgrades and a special ability
- 3 maps: Cedar Lake, North Campus and Bridge Crossing
- Sound effects and music
- Progress and achievements save in your browser

This copy runs on its own. The shared leaderboard and sign-in only exist in the claude.ai version.
